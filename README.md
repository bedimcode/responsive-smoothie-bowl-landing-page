# Responsive Smoothie Bowl Landing Page 

This project is part of a step-by-step YouTube tutorial in which we build a responsive smoothie bowl landing page from scratch using HTML CSS & JavaScript.

### 🎬 [Watch the Demo & Code](https://youtu.be/6epTavZWf5k) 

![preview img](/preview.png) 

### 📌 Project Features
- Responsive Smoothie Bowl Landing Page Using HTML CSS JavaScript | Mobile First
- Clear and semantic HTML structure.
- Use of CSS variables and modern JavaScript functions.
- With modern, sliding animations.
- Developed first with the Mobile First methodology, then for desktop.
- Compatible with all mobile devices and with a beautiful and pleasant user interface.
